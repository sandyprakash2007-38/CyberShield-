04 / FIELD ACADEMY

Learn the fundamentals

Short, beginner-friendly explainers for the ideas behind a secure monitoring workflow.

What is GPS spoofing?

It is a type of interference where a receiver is misled by false positioning signals. In real systems, detecting it is difficult and requires carefully validated methods and sensor context.

Why verify commands?

Command authentication helps a system distinguish authorized instructions from untrusted ones. Real implementations need secure key handling, testing and a defined recovery process.

What is telemetry?

Telemetry is status information sent by a system, such as position estimates, battery level or communication quality. Monitoring it can help operators notice unexpected changes.

Why keep an incident log?

A clear log records what was observed, when it happened, severity and follow-up status. It supports review and learning without assuming every alert is a confirmed attack.

05 / OPERATIONS FAQ

Before you deploy

Is this connected to a real drone?

No. CyberShield is a website prototype using simulated examples. It does not connect to, command or monitor physical drones.

Does it guarantee threat detection?

No. It is an educational demonstration, not a validated cybersecurity product. The scenario descriptions are illustrative only.

Who is it for?

Students, educators and people exploring cybersecurity concepts for unmanned systems, including those interested in defense and aerospace.
